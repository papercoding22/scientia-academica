## Yêu cầu đề bài

Thực hiện bài thực hành **Dò tìm mật khẩu bằng tấn công chủ động** trong môi trường Windows
được kiểm soát. Theo phần giảng viên trình bày, cần làm quen với các công cụ quản lý local user
và group, local security policy, Event Viewer; mô phỏng việc dò mật khẩu chủ động trên tài khoản
của chính mình hoặc máy ảo; quan sát log đăng nhập/cơ chế khóa tài khoản; và nêu biện pháp bảo vệ.

> ❓ **CẦN XÁC MINH:** Transcript nói bài thực hành có 5 trang nhưng file đề gốc chưa có trong
> `brief/`. Khi nhận được file từ LMS/Teams, đặt nguyên bản vào `brief/` rồi đối chiếu lại từng bước.

> *Nguồn: buổi L07, 2026-08-26 — giảng viên: “Bài thực hành của mình là bài thực hành 3”; mục
> tiêu là dò tìm mật khẩu chủ động trên Windows, dùng Local Users and Groups, local security policy
> và Event Viewer; hạn đến 2026-09-02, dự phòng 2026-09-03.*

Đề bài gốc: [`brief/`](brief/)
