Dynamic Data Masking (DDM) là gì?

DDM che khuất dữ liệu nhạy cảm tự động ở tầng database — user không có quyền UNMASK chỉ thấy giá trị đã được che.

Các hàm mask phổ biến

  • default() — che toàn bộ (xxxx)
  • partial(2,'xxx',2) — giữ đầu/cuối
  • email() — aXXX@XXXX.com
  • random(1,10) — số ngẫu nhiên

Ứng dụng trong hệ thống

  • SDT tài xế/khách hàng → partial mask
  • Số tài khoản ví → default mask
  • Admin có quyền UNMASK
  • Report user chỉ thấy dữ liệu che
