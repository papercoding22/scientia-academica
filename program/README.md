## Nhịp bảo trì

**Cuối mỗi học kỳ**, chạy đủ chuỗi này:

1. Cập nhật `transcript.md` — điểm vừa có
2. Tick trạng thái trong `curriculum.md`
3. Đối chiếu lại `study-plan.md` — kỳ tới đăng ký môn gì
4. Tính lại tiến độ ở file này
5. Xem lại `specialization/` — học kỳ vừa rồi có làm đổi ý không
